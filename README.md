## 为什么搬瓦工香港卖这么贵

钱基本都花在带宽和线路上，配置反而是次要的。

线路层面，香港 CN2 GIA 机房对中国电信走双向全程 CN2 GIA（AS4809），联通接 AS9929 高端专线，移动走 CMI 直连，三网都不绕路。搬瓦工官方对这条线路的描述是"Direct route via China Telecom (CN2 GIA), China Unicom, China Mobile"，在行业里算高规格承诺。

延迟更能说明问题。美西机房走 CN2 GIA 到国内普遍 130–180ms，东京大约 60–90ms，香港对华南用户可以低到 10–30ms，华东也只在 30–50ms。做游戏加速、直播推流、实时数据这类业务，30ms 和 150ms 是能明显感知的差距。

至于这个价怎么来的，成本结构摆在那里：按第三方资料的估算，亚洲 CN2 GIA 带宽采购价约每 Mbps 每月 80–120 美元，是洛杉矶机房的 10–15 倍。同样的价钱放在搬瓦工自己的 CN2 GIA-E 上，能买到 4核 8GB 加 2TB 流量。香港套餐的溢价买到的是网络质量，不是算力。

社区整理的晚高峰测速数据也支持这个判断：下载速度能跑到 700Mbps 以上，三网丢包率低于 1%。在香港 VPS 市场里，这属于第一梯队的表现。
